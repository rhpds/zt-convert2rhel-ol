= Convert to RHEL from Oracle Linux
Convert2RHEL allows you to migrate in place to Red Hat Enterprise Linux from several Linux operating systems, including Rocky Linux, Oracle Linux, CentOS, and Alma Linux. In this lab, you will use Convert2RHEL to convert an Oracle Linux 9.7 system to Red Hat Enterprise Linux 9.7.
== Install Convert2RHEL
Install Convert2RHEL.
[source,bash,run]
----
sudo dnf install -y convert2rhel
----
