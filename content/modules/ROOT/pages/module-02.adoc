Convert2RHEL looks for things that are not supported by RHEL as part of its analysis, and it's spotted Datefudge, utility that pretends that the system time is different. We can leave this in place if we wish, but it isn't supported by RHEL. As such, if the proram is not needed, this is a good time to remove it.
=== Remove Datefudge and disable the associated Oracle Linux repo
[source,bash,run]
----
dnf config-manager --disable ol9_distro_builder
dnf remove -y datefudge
----
