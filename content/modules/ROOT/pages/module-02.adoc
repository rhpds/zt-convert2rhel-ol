== Analyze and Remediate
=== Perform the pre-conversion analysis
[source,bash,run]
----
sudo convert2rhel analyze --org 12451665 --activationkey convert2rhel -y

----
You will see a message warning that a package is causing issues with the conversion:
```
========== Error (Must fix before conversion) ==========
(ERROR) RHEL_COMPATIBLE_KERNEL::INCOMPATIBLE_VERSION - Incompatible booted kernel version
     Description: Please refer to the diagnosis for further information
     Diagnosis: The booted kernel version is incompatible with the standard RHEL kernel. Booted kernel version '6.12.0' does not correspond to the version '5.14.0' available in RHEL 9
     Remediations: To proceed with the conversion, boot into a kernel that is available in the Oracle Linux Server 9 base repository by executing the following steps:

    1. Ensure that the Oracle Linux Server 9 base repository is enabled
    2. Run: yum install kernel
    3. (optional) Run: grubby --set-default /boot/vmlinuz-`rpm -q --qf "%{BUILDTIME}\t%{EVR}.%{ARCH}\n" kernel | sort -nr | head -1 | cut -f2`
    4. Reboot the machine and if step 3 was not applied choose the kernel installed in step 2 manually
```

=== Switch to a standard kernel
[source,bash,run]
----
sudo dnf -y install kernel-core
sudo grubby --set-default /boot/vmlinuz-`rpm -q --qf "%{BUILDTIME}\t%{EVR}.%{ARCH}\n" kernel-core | sort -nr | head -1 | cut -f2`
sudo reboot
----
